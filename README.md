## Leistungen

| Leistung | Worum es geht |

## Wie wir bauen

- **Datenfluss zuerst.** Bevor gebaut wird, steht fest, welche Daten ein System sieht, wo sie verarbeitet werden und was davon beim Anbieter des Modells landet. Wo es nötig ist, bleiben die Daten im Haus oder auf Servern in der EU.
- **Prüfbar trotz Sprachmodell.** LLM-Funktionen bekommen Evals, weil ihre Antworten nicht jedes Mal gleich ausfallen.
- **Der Mensch behält die Kontrolle.** Oberflächen, in denen KI mitarbeitet, zeigen, was das Modell vorschlägt, und lassen die Entscheidung beim Anwender.
- **Anbinden statt danebenstellen.** Neue Funktionen hängen an den Bestandssystemen, nicht an einer weiteren Insellösung.
- **Nach dem Go-live noch da.** Wartung, Monitoring und die Pflege von Modellen und Prompts gehören zum Angebot.

**Stack:** Java · Spring Boot · Angular · TypeScript
